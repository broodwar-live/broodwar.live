## Features

- Every game is automatically saved as `LastReplay.rep`
- Approved organizations can run StarCraft leagues through the client

## Fixes

- Burrowed units can no longer be stacked
- Fixed a Vulture exploit that crashed games, an exploit for setting other players' rally points, and a multi-command hack that crashed Mac players

No balance changes.
